# CMS Quick Start Guide for Content Managers

Fast-track guide to using the Decap CMS admin panel.

## 5-Minute Setup

### Before You Start

You need:
1. Email address invited by administrator
2. Signup confirmation email from Netlify
3. Your password (created during signup)

### Login to CMS

1. Visit: `https://your-site.netlify.app/admin`
2. Click "Login with Netlify"
3. Enter your email
4. Enter your password
5. Click "Login"

**Bookmark this URL!** You'll need it often.

---

## Publishing Your First Post

### Create a Blog Post

1. **Click "Blogs"** in left sidebar
2. **Click "New"** button (top right)
3. **Fill out the form:**

   | Field | What to do |
   |-------|-----------|
   | Title | Your article title |
   | Description | 1-2 sentence summary |
   | Author | Your name |
   | Publish Date | When to publish |
   | Category | Choose one from dropdown |
   | Featured Image | Click to upload cover image |
   | Body | Write your article in markdown |

4. **Click "Save"** (saves as draft)
5. **Click "Publish"** when ready

**That's it!** Your post goes live in 1-2 minutes.

## Quick Reference

### Markdown Formatting

**Make text bold:**
```
**bold text** → bold text
```

**Make text italic:**
```
*italic text* → italic text
```

**Create headings:**
```
## Big Section

```

**Create bullet list:**
```

- Item 3
```

**Create numbered list:**

## Uploading Images

### How to Add Images

1. In the markdown editor, position cursor where you want image
2. Click "Upload" button below text editor
3. Select image from computer
4. Wait for upload to complete
5. Image path automatically added: `![](/uploads/filename.jpg)`

### Image Tips

- Keep file size under 5MB
- Use JPG or PNG format
- For featured images: 1200x600px works best
- Add descriptive alt text in square brackets

## Publishing Content

### Three Publishing States

**Draft** (saved but not published)
- Only visible to logged-in users
- Can edit anytime
- Use for work in progress

**Scheduled** (set for future date)
- Set publish date
- Auto-publishes on that date
- Good for planning ahead

**Published** (live now)
- Everyone can see it
- Shows on website immediately
- Can still edit after publishing

### Publish Your Content

1. **Click "Publish"** button
2. **Choose date** (today or future)
3. **Click "Publish"**
4. **Wait 1-2 minutes** for site to update
5. **Refresh website** to see your post

---

## Editing Content

### Edit Published Content

1. **Click collection** (Blogs, Publications, etc.)
2. **Click on the article** you want to edit
3. **Make changes** in the form
4. **Click "Save"**
5. **Wait 1-2 minutes** for site update

### Edit Without Publishing

1. Make changes
2. Click "Save" (NOT Publish)
3. Changes save as draft
4. Others see old version
5. Click "Publish" when ready

## Creating a Publication

### Add a Research Paper

1. **Click "Publications"**
2. **Click "New"**
3. **Fill form:**
   - Title: Paper title
   - Description: Abstract or summary
   - Author: Researcher name(s)
   - Date: Publication date
   - Category: Research type
   - Featured Image: Paper cover/thumbnail
   - PDF File: Upload PDF or link to PDF
   - Body: Description and content

4. **Upload PDF:**
   - Click "Upload" in PDF File field
   - Select PDF from computer
   - Click "Publish" when done

## Common Tasks

### Find Your Published Post

**In CMS:**
1. Click collection
2. Scroll through list
3. Your post shows with date

**On Website:**
1. Navigate to Blogs/Publications/Newsletter page
2. Find your post in the list
3. Click to view full article

### Update Featured Image

1. Open article
2. Click featured image thumbnail
3. Click "Remove" to delete old
4. Upload new image
5. Save and publish

### Delete a Post

1. Open article
2. Click menu (⋯) in top right
3. Click "Delete"
4. Confirm deletion
5. **Post is gone!** (Can't undo)

**Tip:** Instead of deleting, unpublish and save as draft if unsure.

### Unpublish a Post

1. Open article
2. Click "Unpublish"
3. Post no longer visible on website
4. Still exists in CMS for editing
5. Can republish anytime

## Troubleshooting

### Post doesn't appear after publishing

**Solution:**
1. Wait 2-3 minutes for rebuild
2. Hard refresh website (Ctrl+Shift+R)
3. Check post is actually "Published"
4. Verify date is not in future

### Image won't upload

**Solution:**
1. Try JPG instead of PNG
2. Reduce file size (compress)
3. Check filename has no special characters
4. Try different image

### Can't login

**Solution:**
1. Clear browser cache (Ctrl+Shift+Delete)
2. Try incognito/private browsing
3. Check email/password correct
4. Wait 5 minutes and try again
5. Contact administrator

### Published content looks wrong

**Solution:**
1. Check markdown syntax
2. Remove extra spaces/indentation
3. Ensure links are correct format
4. Test in preview first
5. Refresh browser cache

## Writing Tips

### Good Post Titles

- Clear and descriptive
- Include keywords
- Reasonable length (50-70 chars)
- **Example:** "Gender Identity Recognition Laws in 28 European Countries"

### Good Descriptions

- 1-2 sentences
- Summarize main point
- Make people want to read
- **Example:** "Examining the evolving legal frameworks for gender identity recognition across European jurisdictions and their implications for trans and non-binary people."

### Good Markdown Structure

```markdown
## Introduction
Why this topic matters.

## Key Points
- Point 1
- Point 2
- Point 3

## Analysis
Deep dive into details.

## Conclusion
Summary and takeaway.
```

### SEO Tips

- Use keywords in title
- Write compelling description
- Use headings properly
- Link to related articles
- Add relevant images
- Use meaningful slug (filename)

## Best Practices

✅ **Do:**
- Proofread before publishing
- Use consistent formatting
- Include featured images
- Update old posts with new info
- Save drafts regularly
- Test links before publishing

❌ **Don't:**
- Delete content without backup
- Publish work in progress
- Use all CAPS for emphasis
- Write extra-long paragraphs
- Forget to add images
- Publish immediately without review

## Workflow Example

### Full Publishing Workflow

1. **Day 1 - Write:**
   - Create new blog post
   - Write draft content
   - Save (don't publish yet)

2. **Day 2 - Review:**
   - Review draft
   - Fix typos/formatting
   - Add images
   - Save changes
   - Preview to check layout

3. **Day 3 - Publish:**
   - Final review
   - Click "Publish"
   - Set date to today
   - Wait 2 minutes
   - Share post on social media
   - Monitor comments

4. **Later - Update:**
   - Make corrections if needed
   - Save without republishing
   - Or publish update announcement

## Frequently Asked Questions

**Q: How long until my post appears?**
A: 1-2 minutes for Netlify to rebuild the site.

**Q: Can I schedule posts?**
A: Yes! Set future date when publishing.

**Q: Can I edit posts after publishing?**
A: Yes! Just click edit and save changes.

**Q: Can I delete posts?**
A: Yes! But it can't be undone.

**Q: Can I upload large files?**
A: Keep files under 10MB. Images under 5MB recommended.

**Q: Who can see my drafts?**
A: Only logged-in CMS users.

**Q: Do I need technical skills?**
A: No! The CMS is designed for non-technical users.

**Q: Where are my files stored?**
A: In GitHub. Netlify automatically syncs and publishes.

**Q: What if I make a mistake?**
A: Git tracks all changes. Can usually revert in Netlify.
